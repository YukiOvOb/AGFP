# 敏捷管理（Member 1 公共职责）

Member 1 的公共职责是 **整理需求、管理任务、推进 Sprint**（团队分工说明）。本目录是这些工作的产出，按 Sprint 顺序：

| Sprint | Member 1 的任务 | 文档 |
| --- | --- | --- |
| Sprint 0 | 整理需求和任务清单；说明搜索和预约怎样操作 | [需求与任务清单](backlog.md)、[UC01 用例说明](../uc01-search-and-reserve.md) |
| Sprint 0–4 | 每个 Sprint 的目标、分工、配合方式和完成标准 | [Sprint 计划](sprint-plan.md) |
| Sprint 1–2 | 开发搜索、可用时间、提交预约；完善预约规则；协助整合主要业务流程 | [接口合同](../contracts/equipment-and-reservation.md)、代码与测试（见 UC01 文档第 6 节） |
| Sprint 3 | 整理任务完成情况和演示流程 | [Sprint 状态与风险](sprint-status.md)、[演示脚本](demo-script.md) |
| Sprint 4 | 汇总任务、Sprint 和敏捷开发证据 | [敏捷证据索引](agile-evidence.md) |

更新规则：每周例会后由 Member 1 更新 `sprint-status.md`；任务在 GitHub Projects 看板上流转（To Do → In Progress → Review → Testing → Done），本目录记录每个 Sprint 结束时的快照和链接，作为报告证据。
